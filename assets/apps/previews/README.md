# Original product captures

These assets are resized WebP exports of existing screenshots. Application UI is not generated or redrawn.

- Trailo and Subby: original captures already in this repository and in the personal portfolio.
- Jedziemy: original theory course, practice and answer-feedback captures, and app icon from the personal portfolio.
- Doso: current native captures from the Doso project's `artifacts/app-store/raw/` directory (Today, medications, history, family, schedule editor), plus the current mascot icon selected in its app configuration. These supersede the earlier health-dashboard images and blue icon.
- Twoja Sieć: original feed, events and alerts captures from the personal portfolio.
- Charmy Books: historical website and creator captures from the personal portfolio. They retain their earlier JustMine branding and are labeled as historical on the website.
- Arie: browser capture of the existing local Arie website. This is a website screenshot with an illustrative demo, not a native-app capture. The site and archive explain that development is paused and historical download labels are not current availability.
- Solvee continues to use the existing original store screenshots under `assets/apps/` and `assets/apps/gallery/`.

`scripts/prepare_assets.py` exports these assets when the neighboring source projects are present. Deployment only needs the committed files.
